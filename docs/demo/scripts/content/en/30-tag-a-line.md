# Tag a line

A tag marks a line as something: a thing to do, something important, a question to answer.
Click in a line, then **Home** and the Tags box. Asking for the same tag again takes it off.

## To do

- [ ] Open this notebook
- [x] Read the welcome page
- [ ] Tick the box above by clicking it

A to-do line is a task list item, which every Markdown reader understands.

## The other tags

#important Leave on Friday, not Saturday.

#question Does the train stop at the airport?

#idea Keep the tickets in the page, not in the mail.

#remember The booking reference is in the attached file.

NoteCraft draws the mark instead of the word, but the word is what is in the file, so your notes
stay readable in any editor and searchable from a terminal. A word that only looks like a tag,
like #ideas without a space after it, is left alone.

## Find tagged notes

Choose **Home > Find Tags** to open the Tags Summary pane. Each result shows its tag,
note text, notebook, section and page. Choose a result to open the page and focus that line.

Use **Find tags in** to select the current page, section, notebook or all open notebooks.
Page scope excludes subpages. **Only incomplete To Do** shows unchecked tasks.
**Refresh tags** reads the files again, including changes made in another program.
